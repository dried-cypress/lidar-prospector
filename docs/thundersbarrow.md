# Thundersbarrow

The development target is Thundersbarrow Hill near Brighton. Keep analysis in EPSG:27700.

The report should make three things visually distinct:

1. LiDAR terrain, using a neutral high-contrast multidirectional hillshade.
2. Known Historic England AIM Detailed Mapping, using Historic England's published feature colours and direct record links.
3. LiDAR terrain anomalies not already covered by the known Detailed Mapping layer.

Known features are evidence. Anomaly candidates are prompts for archaeological inspection and must not be presented as confirmed sites.
